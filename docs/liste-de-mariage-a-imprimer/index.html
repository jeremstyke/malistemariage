Comment l'utiliser à deux

Imprimez deux exemplaires, cochez chacun de votre côté, puis comparez. Ce que vous avez coché tous les deux va directement dans la liste. Le reste se discute autour d'un café.

Une version papier pour les invités ?

Pour les grands-parents qui ne commandent pas en ligne, imprimez la liste de vos articles avec leur prix. Un proche peut ensuite passer la commande pour eux depuis la liste en ligne, pour que l'article soit bien marqué comme offert. Voyez notre guide pour offrir un cadeau sur une liste Amazon.

Questions fréquentes

La liste imprimée suffit-elle pour les invités ?

Elle aide à choisir, mais pour éviter les doublons, l'achat doit passer par votre liste en ligne. Un proche peut commander pour les invités qui ne sont pas à l'aise avec Internet.
